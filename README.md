# VS Instituto de Beleza — site de agendamento

Site completo do salão: a cliente agenda online (serviço, profissional, dia e horário) e recebe um código para consultar, remarcar ou cancelar. A equipe tem uma área própria com login (e-mail e senha) para ver a agenda do dia, e a administração cadastra serviços, profissionais, acessos e informações do salão, além de acompanhar o fechamento financeiro.

- **Colocar no ar grátis (Render + Neon):** veja [COMO-PUBLICAR.md](COMO-PUBLICAR.md).
- **Tudo roda junto:** um único servidor Node entrega o site e a API; o banco é PostgreSQL.
- **Sem dependência do Replit ou do Clerk.**
